# 00. 처음 시작하기 — 재환·위진 전용

> 이 문서는 **컴퓨터로 개발을 한 번도 안 해본 사람**을 위해 썼습니다.
> 위에서부터 순서대로, 한 줄씩 따라 하세요. 건너뛰지 마세요.
> 막히면 **그 자리에서 멈추고 카톡방에 스크린샷**을 올리세요. 혼자 30분 붙잡지 마세요.

---

## 들어가기 전에: 지금부터 나올 단어 4개

| 단어 | 진짜 의미 | 비유 |
|---|---|---|
| **Git** | 내 컴퓨터에서 코드의 변경 기록을 남기는 프로그램 | 한글 파일의 "저장" + "되돌리기" |
| **GitHub** | 그 기록을 인터넷에 올려 셋이 공유하는 사이트 | 코드 전용 구글 드라이브 |
| **터미널** | 마우스 대신 글자로 컴퓨터에게 명령하는 창 | 검은 화면. 무섭지 않습니다 |
| **클로드 코드** | 터미널에서 대화하며 코드를 짜주는 AI | 옆자리 선배 |

**중요:** 이 중에 외워야 하는 건 없습니다. 이 문서를 볼 때마다 다시 보면 됩니다.

---

## 1단계. 프로그램 3개 설치하기 (30분)

### 1-1. Git 설치
1. https://git-scm.com/download/win 접속
2. 자동으로 다운로드가 시작됩니다 (안 되면 "Click here to download" 클릭)
3. 다운로드된 파일 실행 → **모든 화면에서 그냥 `Next`** → 마지막에 `Install`
   - 중간에 영어가 잔뜩 나오지만 아무것도 바꾸지 마세요. 기본값이 정답입니다.
4. 설치 끝나면 `Finish`

### 1-2. Node.js 설치
1. https://nodejs.org 접속
2. 왼쪽의 **LTS** 라고 적힌 초록 버튼 클릭 (오른쪽 말고 왼쪽!)
3. 다운로드된 파일 실행 → 계속 `Next` → `Install`

### 1-3. VS Code 설치 (코드를 보는 창)
1. https://code.visualstudio.com 접속 → `Download for Windows`
2. 실행 → 계속 `다음`
3. **"Code(으)로 열기" 작업을 Windows 탐색기 파일/디렉터리 상황에 맞는 메뉴에 추가** 항목이 나오면 **꼭 체크**하세요. 나중에 편합니다.

### 1-4. 설치가 됐는지 확인하기
1. 키보드에서 **Windows 키**를 누르고 `cmd` 를 친 뒤 Enter → 검은 창이 뜹니다. 이게 **터미널**입니다.
2. 아래를 한 줄씩 치고 Enter:

```bash
git --version
```
```bash
node --version
```

- `git version 2.xx.x` / `v22.xx.x` 처럼 숫자가 나오면 **성공**입니다.
- `'git'은(는) 내부 또는 외부 명령...` 이라고 나오면 →
  **① 검은 창을 완전히 닫고 새로 여세요.** (설치 전에 열어둔 창은 새 프로그램을 못 찾습니다)
  **② 그래도 안 되면 재부팅.** ③ 그래도 안 되면 카톡방에 스크린샷.

---

## 2단계. GitHub 계정 만들기 (10분)

1. https://github.com/signup 접속
2. 이메일 → 비밀번호 → **Username(아이디)** 입력
   - 아이디는 **영어 소문자와 숫자**로. 팀원이 알아볼 수 있게 지으세요. 예: `jaehwan-dev`, `wijin-kim`
   - 이 아이디는 나중에 바꾸기 번거로우니 신중하게.
3. 이메일로 온 인증번호 입력
4. "무료(Free)" 플랜 선택
5. **완료되면 카톡방에 자기 GitHub 아이디를 보내세요.** 규민이 저장소에 초대합니다.

### 2-1. 초대 수락하기
규민이 초대하면 가입한 이메일로 초대 메일이 옵니다.
→ 메일의 초록 버튼 `View invitation` → `Accept invitation` 클릭. 끝.

---

## 3단계. 내 컴퓨터에 Git 이름표 붙이기 (2분)

Git은 "누가 이 코드를 고쳤는지" 기록합니다. 그 이름을 미리 알려줘야 합니다.
터미널에서 아래 두 줄을 치세요. **따옴표 안만 본인 것으로 바꾸세요.**

```bash
git config --global user.name "jaehwan-dev"
```
```bash
git config --global user.email "본인이_github에_가입한_이메일@example.com"
```

⚠️ 이메일은 **GitHub 가입에 쓴 이메일과 똑같아야** 합니다. 다르면 커밋에 내 얼굴이 안 뜹니다.

---

## 4단계. 프로젝트 코드 내려받기 (10분)

### 4-1. 코드를 놓을 폴더 만들기
터미널에서:

```bash
cd %USERPROFILE%\Desktop
```
> `cd` = "이 폴더로 이동해라". 지금 바탕화면으로 이동한 겁니다.

```bash
mkdir projects
```
> 바탕화면에 `projects` 폴더가 생깁니다. (이미 있으면 에러가 나는데, 무시하고 다음으로)

```bash
cd projects
```

### 4-2. 저장소 복제(clone)하기
`clone` = GitHub에 있는 코드를 내 컴퓨터로 통째로 복사해오는 것.

```bash
git clone https://github.com/규민아이디/idea-vote-app.git
```
> 실제 주소는 규민이 카톡방에 올려줍니다. 그걸 그대로 복사해서 쓰세요.

이때 GitHub 로그인 창이 뜹니다 → `Sign in with your browser` 를 눌러 브라우저에서 로그인하면 됩니다.

```bash
cd idea-vote-app
```

### 4-3. 필요한 부품 설치

```bash
npm install
```
> 이 프로젝트가 쓰는 남의 코드(라이브러리)를 한꺼번에 내려받습니다. **2~5분 걸립니다.** 글자가 폭포처럼 쏟아지는 게 정상입니다. 마지막에 `added ... packages` 가 나오면 성공.

### 4-4. 비밀 열쇠 파일 만들기

```bash
copy .env.example .env.local
```

그다음 규민이 **카톡 개인톡으로** 보내준 두 줄을 `.env.local` 에 붙여넣습니다.
(VS Code로 폴더를 열어 `.env.local` 파일을 클릭하면 편집할 수 있습니다.)

⚠️ 이 값은 **절대 카톡 단톡방이나 GitHub에 올리면 안 됩니다.** 우리 데이터베이스 열쇠입니다.

### 4-5. 실행해보기

```bash
npm run dev
```

`Ready in 2.1s` 같은 글자가 나오면 → 브라우저에서 **http://localhost:3000** 접속.
아이디어 보드가 뜨면 **여러분은 방금 개발 환경 구축을 끝냈습니다.** 🎉

> 끄고 싶으면 터미널에서 `Ctrl + C`.

---

## 5단계. 클로드 코드 설치하기 (5분)

터미널에서:

```bash
npm install -g @anthropic-ai/claude-code
```

그다음 프로젝트 폴더에서:

```bash
claude
```

처음 실행하면 로그인하라고 합니다 → 브라우저가 열리면 결제한 Pro 계정으로 로그인.

이제 `claude` 안에서 한국어로 말을 걸면 됩니다:

> "지금 내 브랜치가 뭔지 알려줘"
> "이슈 12번 작업하려고 해. 브랜치부터 만들어줘"

---

## 자주 나는 에러 3가지

| 화면에 뜬 글자 | 뜻 | 해결 |
|---|---|---|
| `'npm'은(는) 내부 또는 외부 명령...` | Node.js가 설치 안 됨 | 재부팅 후 1-2단계 다시 |
| `fatal: not a git repository` | 프로젝트 폴더 밖에 있음 | `cd %USERPROFILE%\Desktop\projects\idea-vote-app` |
| `Port 3000 is already in use` | 이미 서버가 켜져 있음 | 다른 터미널 창에서 `Ctrl+C`, 또는 그냥 3001 포트로 접속 |
